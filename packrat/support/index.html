Pack Rat Support

Pack Rat helps you scan moving boxes, save what is inside, and find the right box later with a searchable inventory.

Common questions

  • Camera access is used to photograph boxes and items for inventory tracking.
  • Photo-library access is used to import existing box and item photos.
  • Microphone and speech-recognition access are used only when you dictate box or item notes.
  • iCloud sync requires the user to be signed in to iCloud and have iCloud available for Pack Rat.
  • Item extraction runs with local device features when available.
