Sofal Support

Sofal is a pottery studio tracker for pieces, clay bodies, glazes, photos, notes, and firing history.

Common questions

  • Camera access is used to photograph pieces, glaze labels, and clay bags.
  • Photo-library access is used to import existing studio photos.
  • iCloud sync requires the user to be signed in to iCloud and have iCloud available for Sofal.
  • Optional online AI research is off by default and requires a user-provided provider API key in Settings.
